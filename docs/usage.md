# 使用说明

[← 返回 README](../README.md)

## 启动

```bash
python xbox_vibe.py
```

程序会在默认浏览器中打开本地页面，通常为 `http://127.0.0.1:8765/`。如果端口被占用，会自动尝试其他本地端口。

在页面中：

1. 页面加载时会自动运行一次环境检查，在 **环境检查** 区域确认手柄和辅助功能权限可用；需要重新检查时点击 **运行环境检查**。
2. 点击 **启动手柄映射**，等待 **手柄** 状态显示已连接。
3. 切换到 Claude Code、终端或其他目标应用，并让目标窗口保持焦点。
4. 使用手柄执行操作；浏览器页面会显示实时高亮和最近一次动作。
5. 完成后点击 **停止** 停止映射，或点击 **退出应用** 退出程序。

工具条上还有 **打开配置**（打开配置文件）和 **辅助功能权限**（打开 macOS 辅助功能设置）两个入口。

> 映射发送的是系统级按键，动作会作用于当前获得焦点的应用。开始操作前，请先确认焦点位于正确窗口。

页面中的 **当前映射** 区域展示当前生效的按键映射，与[按键映射](controller-mapping.md)表格一致；使用自定义配置后，请以该区域为准。

## 无界面模式

直接在终端运行 Bridge，不打开浏览器说明页：

```bash
python xbox_vibe.py --headless
```

按 `Ctrl+C` 停止。

## 调试手柄索引

只打印原始按钮和轴事件，不执行映射动作：

```bash
python xbox_vibe.py --debug
```

如果手柄按键没有触发预期操作，请用此模式确认 macOS / pygame 上报的按钮索引。

## 命令行参数

```bash
python xbox_vibe.py --help
```

| 参数 | 作用 |
| --- | --- |
| `--doctor` | 检查手柄、辅助功能权限和 tmux |
| `--headless` | 不启动浏览器页面，直接运行 Bridge |
| `--debug` | 打印原始手柄事件，不发送任何按键 |
| `--init-config` | 创建默认用户配置文件 |
| `--print-config-path` | 输出当前配置文件路径 |
| `--show-mapping` | 输出合并配置后的当前映射 |
| `--config PATH` | 使用指定的 JSON 配置文件 |
