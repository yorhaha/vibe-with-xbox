# 常见问题

[← 返回 README](../README.md)

## 检测不到手柄

- 确认手柄已经在 macOS 蓝牙设置中连接，而不是只完成配对。
- 退出并重新启动程序，再运行 `python xbox_vibe.py --doctor`。
- 运行 `python xbox_vibe.py --debug`，确认 pygame 能收到按钮和摇杆事件。
- 当前版本使用系统识别到的第一个手柄；同时连接多个手柄时，请先断开其他设备。

## 按键没有作用

- 确认已经点击 **启动手柄映射**。
- 在 **系统设置 → 隐私与安全性 → 辅助功能** 中确认权限已经开启。
- 授权后完全退出并重新启动 Terminal、Python 或 `Vibe with Xbox.app`。
- 确认目标应用处于前台并获得键盘焦点。

## X 键不能作为右 Option 使用

- X 的行为与物理修饰键一致：按住 X 时按下右 `Option`，松开 X 时释放。
- 需要组合键时，请保持 X 按下，再通过键盘或其他输入发送目标按键。
- 如果完全没有反应，请确认辅助功能权限已经授予当前运行程序。

## tmux 按键没有作用

- 用 `command -v tmux` 确认本机已经安装 tmux。
- 用 `tmux list-clients` 确认本机存在已连接的 tmux 客户端。
- SSH 主机上的远端 tmux 不受支持。
- 确认当前终端处于 tmux 会话中。
- RT 会关闭当前窗格；为避免误触，它必须持续按住 0.7 秒。

## 浏览器页面打不开

- 程序默认监听 `http://127.0.0.1:8765/`；端口被占用时会自动改用其他本地端口，请查看终端输出的实际地址。
- 本地页面仅监听 `127.0.0.1`，不会对外网开放，也不要把地址改成 `0.0.0.0`。

## 仍然无法解决

运行 `python xbox_vibe.py --doctor` 和 `python xbox_vibe.py --debug` 收集输出，并在提交 Issue 时附上。
