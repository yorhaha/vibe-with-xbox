# 按键映射

[← 返回 README](../README.md)

浏览器页面中的 **当前映射** 区域始终展示当前生效的映射，本文档说明默认值及每个按键的行为细节。

## 默认映射

| 手柄输入 | 默认操作 | 说明 |
| --- | --- | --- |
| A | `Enter` | 确认当前选项或提交输入 |
| B | `Esc` | 取消、关闭选择器或返回 |
| 按住 X | 按住 macOS 右 `Option` | 松开 X 时释放右 `Option`，可与其他输入组合 |
| Y | `↓` + `Enter` | 下移一项并确认，适合 yes / auto-edit 类提示 |
| 左摇杆上 / 下 | `↑` / `↓` | 持续拨动时自动重复 |
| 右摇杆上 / 下 / 左 / 右 | 切换到对应方向的窗格 | 在当前 tmux session 内切换；每次拨动触发一次 |
| 十字键上 / 下 | 新建上方 / 下方窗格 | 当前终端需处于 tmux 会话 |
| 十字键左 / 右 | 新建左侧 / 右侧窗格 | 当前终端需处于 tmux 会话 |
| LB / RB | 上一个 / 下一个 session | 在多个 tmux session 之间切换 |
| 长按 RT 0.7 秒 | 关闭当前窗格 | 会终止该 tmux 窗格，请谨慎使用 |
| Start | 输入重启指令 | 输入“在本分支commit & push代码，然后温和重启项目”，不自动按 Enter |

LT、摇杆按下、View、Share、Xbox 键，以及左摇杆的左右方向暂未映射。

## 行为细节

### X 键作为右 Option

X 的行为与物理修饰键一致：按住 X 时按下右 `Option`，松开 X 时释放。需要组合键时，保持 X 按下，再通过键盘或其他输入发送目标按键。

### 左摇杆连发

左摇杆推向上或下时，先等待 `repeat_initial_delay`（默认 0.35 秒）再开始连发，之后按 `repeat_rate`（默认 0.08 秒）的间隔重复。推杆方向需超过 `deadzone`（默认 0.5）才会触发。这些参数可在[配置文件](configuration.md)中调整。

### tmux 相关按键

十字键、摇杆方向、LB、RB 和 RT 均通过本机 `tmux` 命令执行，操作时前台窗口无需保持在终端。使用时需要：

- 当前终端处于一个 tmux 会话中。
- 本机至少有一个已连接的 tmux 客户端（`tmux list-clients`）。
- 只控制本机 tmux server，不支持 SSH 主机上的远端 tmux。

RT 会终止当前 tmux 窗格，为避免误触必须持续按住 0.7 秒。

### Start 键

Start 会把“在本分支commit & push代码，然后温和重启项目”输入当前应用，但不会自动按下 `Enter`，你可以先确认文本再自行提交。
